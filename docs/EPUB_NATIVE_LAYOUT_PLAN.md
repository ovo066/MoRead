# EPUB 原生精排实施方案

> 目标：不依赖 WebView，在保留墨知现有分页、选区、批注、朗读和伴读能力的前提下，逐步支持精排 EPUB。

## 1. 样书结论

以 `【精排版】漂亮炮灰[无限]` 为例：

- 它是 EPUB 2，`toc.ncx` 已正确表达多级目录：20 个顶层节点，其中 17 个是卷节点。卷与普通章节在导航文件里都是 `navPoint`，不能靠标题正则稳定区分。
- 精排效果不只来自正文文字，还依赖 XHTML 结构、CSS 层叠、嵌入字体、块背景/边框、卷封页、图片、SVG、ruby 与分页属性。
- 现有导入链把 XHTML 降成 `text.mz` 纯文本和图片 sidecar，适合检索、AI、朗读与统一排版，但无法无损还原上述版式。
- 因此目录层级和正文精排必须分开解决：目录保存原始导航树；正文新增原生布局文档，`text.mz` 继续作为语义与坐标真源之一。

当前已先完成目录侧修复：schema v21 用 `book_toc_entries` 保存顺序、深度、父节点、href、目标章节与子节点标记；阅读目录支持卷级折叠、缩进和当前章节定位。

## 2. 推荐架构

### 双轨内容模型

- **语义轨**：保留当前 `text.mz` + `chapters`，继续服务全文检索、向量索引、AI 引用、朗读和旧书兼容。
- **布局轨**：新增每章原生文档 AST，保存块、行内节点、资源引用和归一化样式，供 `ChapterTypesetter` 分页。
- 两条轨道共享稳定的文本坐标映射。每个可见文本节点记录 `text.mz` 的 UTF-16 起止位置，点击、选区、批注与 AI 引用仍能落回现有坐标体系。

### EPUB 包与资源仓库

- 导入时持久化原 EPUB，或解包到按书隔离的资源目录；不要只保留图片。
- 建立 manifest/spine/navigation 索引，资源统一使用书内规范化路径，处理 `../`、fragment、URL 编码和大小写差异。
- 字体、CSS、图片、SVG 等资源按内容哈希缓存；删除书籍时由统一仓库清理。
- 禁止 XHTML/CSS 访问网络、本地任意路径或执行脚本，所有资源只能解析到当前书包内。

### 原生文档 AST

第一版只建足够稳定的节点，不直接镜像 DOM：

- 块节点：章节根、段落、标题、引用、列表、列表项、分隔线、图片块、容器、显式分页点。
- 行内节点：文本、强调、加粗、删除线、上/下标、ruby、链接、行内图片、软换行。
- 样式快照：字体族/字重/字号/行高、颜色、对齐、缩进、间距、边框、背景、书写方向、分页约束。
- 资源节点只存安全的书内资源 ID，不把二进制塞进 AST。

### CSS 子集与层叠

优先实现电子书高频且能稳定映射到原生排版的子集：

1. 标签、class、id 与简单后代选择器。
2. inline style、`<style>`、外链 CSS，按来源、specificity 和顺序计算层叠。
3. 字体、字号、行高、颜色、文本对齐/缩进/装饰。
4. margin/padding、border、background、宽高与最大宽度。
5. `page-break-before/after/inside`、`break-*`、`orphans`、`widows`。
6. 暂不支持的属性明确忽略并记诊断，不执行 JavaScript，不实现浏览器通用布局。

### 排版与渲染

- 扩展 `ChapterTypesetter`，把当前纯文本段落输入升级为样式化块流；分页结果仍落到可缓存的页模型。
- 文本继续用 Android 原生测量；同一行允许多个 style run，并在分页时保留字符坐标。
- 图片按 intrinsic size、容器宽度与 CSS 限制缩放；块背景、圆角、边框在页模型中生成绘制指令。
- SVG 优先走受控栅格化缓存；ruby 用双层基线布局；嵌入字体经校验后注册为每书字体族。
- 卷封页和整页插图允许生成“固定块页”，但仍由阅读器 Canvas 绘制，不切换渲染内核。

## 3. 分阶段落地

### 阶段 A：资源保真

- 新增 EPUB 包存储、manifest/spine 索引和资源解析器。
- 导入时保留 XHTML、CSS、字体、SVG 与图片引用。
- 建立 AST 与 `text.mz` 坐标映射，输出诊断报告和缓存版本号。

### 阶段 B：正文样式

- 支持段落/标题/列表/引用、行内强调、字体、字号、颜色、缩进、间距和对齐。
- 把样书的正文页、章标题和卷标题作为首批视觉基准。
- 排版失败时按章回退当前纯文本渲染，不让整本书打不开。

### 阶段 C：精排资源

- 支持嵌入字体、块背景/边框、卷封页、SVG 和 ruby。
- 增加图片跨页策略、孤行寡行与强制分页控制。
- 建立按屏幕尺寸、字体设置和主题生成的分页缓存。

### 阶段 D：兼容与验收

- 建立一组 EPUB 2/3 样书快照，覆盖 NCX/nav、纵深目录、共用 href、fragment、竖排与异常 CSS。
- 对每本书记录解析告警、未支持 CSS 属性和回退章节，便于逐步补齐而不是静默丢样式。
- 验收同时覆盖分页、跳章、选区、批注、朗读、搜索和 AI 引用，避免“看起来像原书”但阅读能力退化。

## 4. 当前实现状态（2026-08-25）

### 已接通

- 导入侧已保留 package/spine、XHTML、CSS、字体、图片与 SVG 资源，生成按章布局文档；`text.mz` 仍是搜索、AI、朗读、选区和批注的坐标真源。
- `ChapterTypesetter` 可按章选择原生 EPUB 排版；布局缺失、版本不符或单章异常时继续回退原纯文本路径。
- CSS 已覆盖简单选择器与后代选择器、层叠优先级、inline style、字体/字号/字重/斜体、颜色、行高、字距、对齐、缩进、margin/padding、四边独立边框、圆角、背景、透明度、浮动宽度和强制/避免分页。
- 块容器和跨页装饰已进入页模型；跨页时只在真实首尾页绘制对应圆角和边框，不重复封口。
- 行内 `inline-block` 风格标签已支持水平/垂直盒模型、圆角背景、四边边框、跨行断边和 `break-inside: avoid`，覆盖样书中的弹幕、热度与标签胶囊。
- `box-shadow` 已支持多重外阴影及 `inset` 阴影近似；阴影不占排版空间，同时适用于块卡片和行内标签。
- 嵌入字体保留完整 `@font-face`，运行时按字体族、字重和斜体选择最接近字体面；无精确字体面时继续允许 Android 合成粗斜体。
- ruby 已采用双层基线布局：注音宽度参与换行，基文仍映射原 UTF-16 坐标；SVG 资源通过 AndroidSVG 受控栅格化后进入现有位图缓存。
- 位图渲染已覆盖正文多 style run、块/行内背景、背景图、阴影、独立边框、分隔线、图片、SVG、ruby、嵌入字体和透明度。
- 已修正 Readium 暴露的包根相对 href（如 `Text/Chapter.xhtml`）与 OPF 规范路径（如 `OEBPS/Text/Chapter.xhtml`）不一致的问题；章节、CSS、图片和字体现在统一回到 OPF 路径，并为读取侧保留包根相对别名。
- 布局 sidecar 写入失败不再被静默吞掉；文本版本升至 v4、布局 schema 升至 v2，已导入的 v3 EPUB 会自动重新物化布局，无需用户手工清缓存。
- 已定位“新导入仍是纯文本”的直接原因不是 CSS 解析或 Canvas 能力，而是布局 sidecar 缺失/损坏时被静默降级，以及首次读取与导入修复完成之间的竞态；当前会逐章校验 schema、章节号和 UTF-16 文本长度，不再缓存空布局，修复完成后原位重排当前章及前后章。
- `0.12.0-beta2` 首次设备导入还暴露了 Android ICU 正则差异：未转义的 CSS 右花括号在桌面 JVM 可编译，在 Android 上会触发 `PatternSyntaxException`，导致 `EpubCssStylesheetSet` 类初始化失败并被包装成“EPUB 已损坏”。现已显式转义规则结束符，并增加 Android 仪器测试。

### 当前降级

- `background-size/repeat/position` 尚未形成完整通用模型；样书卷封页使用的 `cover + no-repeat + center` 与当前绘制路径等价，其余组合仍按居中 cover 降级。
- `border-style` 的 dashed/dotted/double、渐变背景、`text-shadow`、复杂 `transform`、绝对定位、flex/grid 和竖排尚未实现。
- `inset box-shadow` 使用 Canvas 模糊描边近似，不保证与浏览器逐像素一致；过长且无法整行容纳的 ruby 会按行片段降级。
- 外部 SVG 文件可栅格化；XHTML 内任意 SVG path/filter DOM 尚未序列化，样书封面的内联 SVG `<image>` 已能抽取其 JPEG 资源。
- `orphans/widows`、完整孤行寡行控制和按屏幕参数持久化分页缓存仍待后续批次。
- 若包本身缺少资源或单章 XHTML 无法解析，该章仍回退纯文本；旧布局 sidecar 会由文本版本迁移重新生成。

### 验证

- JVM 测试覆盖 CSS `rgba`、非对称边框、`display:none` 继承、多重阴影、容器避免分页、跨页装饰封口、行内胶囊、盒模型换行、字体面匹配和 ruby 行带。
- 指定精排样书以模拟 Readium 包根相对 href 的方式验证：311/311 章解析成功，命中 12 个字体面、2,999 个样式块、2,343 个背景/边框块、1,989 个居中块和 6,920 个自定义字体片段；布局正文与数据库正文的规范化差异为 0。
- 阅读控制器回归覆盖“首次无布局回退纯文本，sidecar 随后可用后刷新为居中标题、粗体和装饰块”，防止空结果缓存让整次阅读会话持续丢样式。
- `0.12.0-beta3`（versionCode 56）performance 验收：575 个 JVM 测试和 1 个 Android ICU 正则仪器测试通过，R8 与资源收缩构建成功，APK zipalign 与 v2 签名校验通过。
- MuMu 设备端以同一样书完整导入：生成 311 个章节布局文件、345 个精排资源文件和 783 张图片，最终 performance 包重复导入后直接进入阅读页，日志中无 `ImportCoordinator` 或崩溃异常。
- 构建必须经 `subst M:` 并显式使用仓库内 JDK 17，避免中文路径触发 Gradle/KSP 快照异常。

## 5. 关于 Reeden 参考

参考 APK 是 Flutter 应用。当前拿到的 `base.apk` 在 `lib/x86_64/libflutter.so` 中途截断，Manifest 和后段 assets 缺失；但完整的 ARM64 `libapp.so` 与 `classes.dex` 仍提供了足够线索：包内确有 `flutter_inappwebview`、QuickJS 和 HTML 模板桥接，同时正文相关字符串还出现 `BatchLayoutEngine`、`HorizontalFlowLayoutEngine`、Flutter `SelectableRegion`、`Paragraph::getClosestGlyphInfo`、页锚点与大量可独立开关的 CSS 属性。

因此更可靠的判断是：Reeden 并非把所有阅读能力都交给 WebView，而是至少存在一套自定义排版/分页与 Flutter 选区层；WebView 更明确地用于网页、HTML 分享模板、预览和图片交互等场景。它能同时保留精排、翻页和选词手柄，关键在于布局结果仍输出稳定的字形/字符坐标，并接入 Flutter 的选区机制，而不是简单把章节截图成位图。

墨知更适合沿用现有 `ChapterTypesetter` + Canvas 路线：工作量高于 WebView，但分页手感、主题覆盖、选区坐标、批注与 AI 能力可以保持单一一致的原生模型。

## 6. 暂不纳入

- 温习包、读后卡。
- JavaScript、表单、音视频等浏览器交互能力。
- 一次性追求完整 CSS/HTML 标准；按真实样书和回归集逐步扩大支持面。
