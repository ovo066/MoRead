# 墨知 v1.0.5

本次更新重点改善 AI 伴读的“读回能力”、长对话流式体验与 WebDAV 备份可靠性。

## AI 伴读工具升级

- 新增章节目录工具：识别 EPUB 卷/部层级，TXT 自动回退为章节列表；长目录支持分段读取，防剧透开启时隐藏未读标题。
- 新增划线批注读回：伴读可按章节、作者和关键词查看已有划线及讨论数量，减少重复标注。
- 新增笔记与梗概读回：支持目录浏览、按编号读取全文和长内容续读。
- 阅读进度总览现在包含书籍状态、当前章/全书进度、阅读时长、标签及笔记、梗概、批注、书签存量。
- `write_note` 可按笔记编号更新当前角色自己的笔记；剧情梗概默认滚动更新最新一份，也可明确新建。用户手写内容和其他角色内容保持只读。
- 系统上下文加入上一章、当前章阅读百分比以及最多三条用户划线，优先保留用户主动写下的想法。
- 角色编辑页的工具权限移入独立二级页，改为逐项开关；目录、原文、划线与笔记读取作为基础能力始终可用。

## 伴读对话体验

- 优化流式回答的自动跟随：停留底部时平滑跟随新增内容，主动上滑查看历史后不再抢夺滚动位置。
- 稳定单气泡和多气泡流式切分，减少换行时的气泡重建、尖角变化和视觉跳动。
- 优化过程卡、状态行与最终消息之间的布局衔接。

## WebDAV 备份与恢复

- 自动备份改为轻量包，手动备份保留完整包，减少日常上传体积。
- 增加备份生成、上传、下载和恢复准备进度。
- 恢复包先在后台完成下载、校验与解压，再于重启时替换数据，降低大备份恢复卡顿和失败风险。
- 增加临时文件清理、可用空间检查与轻量备份保留策略。

## 其他修复

- 改善 API 调用日志与伴读批注讨论刷新。
- 补充伴读工具、上下文、流式列表和备份路径相关单元测试。

> Android 8.0 及以上。正式 APK 由 GitHub Actions 使用项目发布证书签名。
