# 墨知 1.0.8

## 相比 1.0.7 的主要更新

### 伴读聊天更稳定，阅读切换更顺畅
- **修复打开历史会话时的闪烁和跳动**：先完成会话与消息准备，再按末尾位置进行首次布局，避免先显示顶部、随后突然跳到最新消息。
- **优化从伴读返回阅读页的卡顿**：复用分页、连续滚动模式的阅读视图和排版缓存，减少返回时的重新创建、加载和排版。
- 改进流式消息的稳定标识、自动跟随与手动滚动；处理中止生成、部分回复保存、切换会话或角色时的隔离，减少内容重复、闪现或串入其他会话的问题。
- 加强长期记忆与上下文的书籍、角色和用户面具边界；书内信息仍受已读范围约束。

### 随读段评：更像角色在一起读书
- **快速模型提醒改用角色口吻短句**：结合角色人设和说话风格，生成不超过 24 字的自然交流，而不是让模型重复“某角色写了几条段评”。提醒生成不额外传入正文、聊天记录或段评内容；失败时使用简短的对话式兜底。
- **明确三种划线样式的选择**：精彩句与描写用荧光，已读内容中的线索与伏笔用波浪线，知识、典故和术语用直线。移除容易让模型只选择荧光的固定示例；不是随机轮换，也不会改写已有批注的样式。
- 段评任务改进为受控串行调度，加入持久化去重、待处理任务边界、额度校验和取消时的原子提交保护，降低快速翻页或频繁切换时的重复生成与误写入风险。
- **修复随读伴读设置页进入时闪一下**的问题，避免存储中的设置加载前先显示默认值。

### 阅读与书架
- **恢复阅读页上方安全区域**：沉浸式隐藏状态栏时仍保留稳定的系统安全边距，并兼顾屏幕刘海；页眉和正文不再因系统栏隐藏而顶到屏幕边缘。
- **读完全书后保持 100% 状态**：完成状态与续读坐标分开保存，回看旧章节不会把已读完的书变回未完成。
- 合入自 1.0.7 发布后已合并的社区改进：**书籍合集、书架拖拽排序、繁简转换及相关定位修复**，感谢 [PR #7](https://github.com/ovo066/MoRead/pull/7) 的贡献。
- 大屏增加自适应书架网格和侧边导航，可选双页阅读、阅读与伴读侧栏并排；手机继续使用适合竖屏的单页布局。
- 改进生图、语音等设置的文本输入与保存，减少输入法组合文字、设置回显和离开页面保存时的干扰。

### 新图标与演示
- 换用新的墨知图标，去除原图外框并适配 Android 自适应图标、安全裁切范围及单色主题图标。

## 升级与使用说明
- 正式版本可在相同签名的旧正式版上覆盖安装。升级前建议使用应用内 WebDAV 备份保留重要资料；不要为升级主动卸载应用。
- performance 与正式版签名不同，不能相互覆盖安装；日常使用请选择本页正式 APK。
- 快速模型口吻提醒是**可选项**，需开启相应设置并配置可用的快速模型，调用可能产生服务商费用；未开启时仍保留免费数量提醒。短句不读取书中具体情节，不等于即时剧情分析。
- 本次模拟器检查不代表所有手机的帧率或耗时基准，也未覆盖各第三方模型的在线调用效果；没有为减少闪烁而取消防剧透或数据隔离约束。
