# MoRead · 墨知 1.0.9

## English

### Bookshelf and reader gestures
- Collection cards stay in place when a book is dragged onto them, and the entire card accepts the drop. Reordering between cards remains available.
- Book long-press menus now appear above the bottom dock. Placement adapts to available space; compact windows can overlap part of the cover, and long menus scroll instead of extending off-screen.
- Pull down and release to add a bookmark in paginated reading. Continuous vertical scrolling is unchanged. Repeating the gesture does not remove an existing bookmark, and cancelled or multi-touch gestures do not add one.

### EPUB import, layout, and storage
- Reuse archive indexes and CSS caches during import to reduce repeated ZIP scans and style parsing. No numerical speedup is claimed without a benchmark.
- Compress EPUB layout data and compact compatible existing caches safely. Storage statistics now include layout data and embedded fonts, with AI-generated illustrations shown separately.
- Improve large cover/full-page artwork fitting and fragment navigation while preserving intentionally small publisher images. Full vertical typesetting is not included.

### Companion and localization
- Improve initial positioning and layout stability when opening companion conversations, and prevent stale asynchronous results from updating a different conversation.
- Bring character persona into proactive annotation prompts and improve optional fast-model reaction handling. Diagnostic logs do not include raw model output or sensitive exception messages.
- The repository README now defaults to English, with a separate Chinese edition. Android string resources and partial English translations cover the updated bookshelf actions, bookmark feedback, and selected import messages. The app is still primarily Chinese; this is not a complete English UI.

### Upgrade notes
- Version **1.0.9**, versionCode **72**; previous stable release: **1.0.8 / 71**.
- Use the officially signed APK attached to this release. It can update an older official installation with the same signature; backing up important data with the app's WebDAV feature is recommended. Do not uninstall the app just to upgrade.
- Performance builds use a development certificate, cannot replace an official installation, and are not included as release assets.
- Automated gesture tests are included, but this release has not received a new physical-device regression pass. EPUB import timing has not been benchmarked.

### Verification
- Local `:app:testDebugUnitTest :app:assembleRelease :app:assemblePerformance` checks all succeeded.
- **1,122 unit tests: 1,119 passed, 3 external-fixture tests skipped, 0 failures.** Machine-local temporary diagnostics are not part of the release test set.
- Release signing was verified against the configured official certificate; the performance build was verified to use the development certificate.

## 中文

### 书架与阅读手势
- **修复合集“躲避”拖入书籍**：靠近合集时保持目标位置稳定，整个合集卡片均可接收书籍；卡片间仍可拖拽排序。
- **长按菜单显示在 dock 之上**：根据可用空间智能调整位置，小窗口允许覆盖部分封面；菜单过长时滚动显示，不再被底部导航挡住。
- **翻页模式下拉添加书签**：下拉到阈值后松手添加，重复下拉不会取消已有书签；连续上下滚动模式不启用，取消或多指手势不会误加书签。

### EPUB 导入、排版与存储
- 复用 ZIP 条目索引和 CSS 缓存，减少导入时的重复扫描与样式解析；尚未以计时基准承诺具体提速比例。
- EPUB 精排数据采用压缩存储，并安全压实兼容的旧缓存；存储统计补齐精排数据与内嵌字体，AI 插图单独列出。
- 改进大幅封面、整页插画适配与书内片段跳转，保留出版方明确设置的小图尺寸；本次不包含完整竖排排版。

### 伴读与本地化
- 改进打开伴读历史时的首屏定位与布局稳定性，防止切换会话后旧异步结果回写。
- 随读段评更完整地使用角色人设，优化可选快速模型口吻提醒；诊断日志不记录原始模型输出和可能含敏感信息的异常消息。
- README 默认英文并提供独立中文版；建立 Android 中英字符串资源基础，覆盖本次书架操作、书签反馈及部分导入进度。应用界面仍以中文为主，**不是全量英文界面**。

### 升级说明
- 版本 **1.0.9**（versionCode **72**），上一正式版为 **1.0.8 / 71**。
- 下载本页的正式签名 APK，可覆盖相同签名的旧正式版。建议先使用应用内 WebDAV 备份重要资料，不要为了升级主动卸载应用。
- Performance 包使用开发证书，不能覆盖正式版，也不作为正式 Release 附件。
- 已包含手势自动化回归，但本次尚未进行新的实机回归；EPUB 导入耗时尚未做基准测试。

- **1,122 项单元测试：1,119 通过、3 项外部样本测试跳过、0 失败**；本机临时诊断测试不计入发布测试集。
