# MoRead · 墨知 1.1.0

## English

### Chapter outlines and characters

- The reader's contents sheet now has **Contents / Outline / Characters** tabs. Generate a chapter recap manually, keep it on your device, and expand or collapse each chapter when revisiting it.
- Outlines are connected chapter recaps, with a synthesis step for long chapters and source evidence behind a disclosure. Different chapters can generate and stop independently, with up to two concurrent model requests.
- The Characters page scans the **entire book**, including unread chapters, after confirmation. Extraction saves verified checkpoints for resuming, keeps the previous guide during updates, and lets you search names or open source passages.
- The navigation sheet uses a fixed content viewport and independent tab scroll states. Its bottom stays attached to the window, and list gestures and background progress updates no longer drag or resize the sheet.
- Generation shows the model, source length, scope, and maximum request count before confirmation. Viewing saved results makes no model request. Configure a chat model for **Batch tasks** in AI services.

### Companion and retrieval

- The library companion supports open-ended chat, on-demand local book lookup, cross-book discussion, and per-book reading boundaries. Optional focus books help guide a discussion; bookshelf organization plans are previewed before application.
- Library chat now supports message editing, deletion, branching, regeneration, and retry. Regeneration reuses the original question, and branches do not inherit a summary of later messages.
- An optional dedicated **Rerank** model can reorder search candidates. Configure a custom provider with a rerank-capable endpoint and assign its rerank model in **AI services**. Leaving it unassigned keeps the existing search behavior; timeout and invalid responses fall back to the original order.
- Search and exact text lookup accept chapter ranges. Annotation lists can filter your marks and AI marks by source and character.

### Reading and local data

- Adjustable automatic scrolling and timed page turns, with a compact reader control sheet. Touch, menus, navigation, backgrounding, and speech playback pause automatic reading.
- Dedicated storage management, per-book index controls, and an explicit option to preserve personal records when removing book content.
- Background/cover image categories, image export, independent app fonts, improved bookmark pull gestures, and companion reading-history statistics.
- EPUB import and artwork/background layout fixes, including resource URI handling and publisher image sizing.

### Upgrade

- Version **1.1.0**, versionCode **74**, Room schema **29**. Existing books, conversations, and saved chapter outlines are preserved by database migrations.
- Install the officially signed APK attached to this release over an official installation with the same signature. Performance builds use the development certificate and are not release assets.
- The interface remains primarily Chinese. Device-specific behavior and paid model/provider compatibility are separate from the automated checks.

### Verification

- Local unit tests, release and performance builds, and Android test source compilation all succeeded.
- **1,285 tests: 1,279 passed, 6 conditional skips, 0 failures.** Skips cover five external EPUB fixtures and the optional local retrieval evaluation.
- Real Compose bottom-sheet tests cover attachment to the window bottom, boundary swipes, tab position restoration, and background progress updates. Both APK versions and certificates were checked. No physical device or paid model service was used in this verification.

## 中文

### 章节大纲与人物

- 阅读目录新增 **目录 / 大纲 / 人物** 三个相邻页签。手动生成章节概括，保存在本机，按章折叠、展开，回读时随时查看。
- 大纲改为读者视角的连贯梗概，交代事件的来龙去脉；长章额外合成为整章内容，原文依据单独折叠。各章可独立生成、停止和重试，最多两个模型请求并发。
- 人物由独立 AI Agent 扫描**整本书**，包括未读章节；确认中明确范围。支持断点继续、姓名查找和原文跳转，更新期间保留上一次完成的资料。
- 修复目录、大纲、人物页上下滑动时的弹层跳动：固定内容视口并保持弹层底部贴边，隔离列表手势，分别保存页签滚动位置，后台进度更新不改变进度栏高度。
- 生成前显示模型、范围、字数及调用上限；查看保存内容不调用模型。使用前在 **设置 → AI 服务 → 批量任务** 分配支持对话的模型。

### 伴读与检索

- 书库伴读不选书也能聊，按需查找本地书籍、跨书讨论，每本书独立限制已读范围；可以选择重点书籍，整理书架先预览方案再确认。
- 书库聊天支持修改、删除、分支、重新生成及中断重试。重生成复用原提问；分支不会带入后续对话的滚动摘要。
- **可选 Rerank 模型**：在自定义供应商中添加“重排”类型模型，再分配到“Rerank（可选）”。默认使用 `/rerank`，也可设置模型专用路径；每次最多 24 个候选、12000 字、5 秒，失败回落原排序，不配置就不调用。
- 语义检索与逐字检索支持章节区间；划线索引支持“我的 / AI”及具体角色筛选。

### 阅读与本地数据

- 自动阅读支持匀速滚动、定时翻页与小半屏设置；触摸、菜单、导航、后台和语音切换会暂停。
- 独立存储管理、按书控制索引，移除正文时可保留个人记录，彻底删除单独确认。
- 背景/封面图片分类、图片导出、独立应用字体、书签丝带手势与“陪伴足迹”统计。
- 改进 EPUB 资源导入、背景和整页插画排版，保留出版方明确指定的小图尺寸。

### 升级

- 版本 **1.1.0**（versionCode **74**），数据库升级到 **29**，迁移保留原有书籍、对话与已保存大纲。
- 使用本页正式签名 APK，可覆盖相同签名的旧正式版；performance 使用开发证书，不作为正式 Release 附件。
- 应用仍以中文为主。机型体验、付费模型和具体供应商兼容性需与自动化测试分开看待。

### 验证

- 本地单元测试、release 与 performance 构建、Android 测试源码编译全部成功。
- **1285 项测试：1279 通过、6 项条件跳过、0 失败**；跳过项为 5 个外部 EPUB 样本及可选本地检索评测。
- 真实 Compose 弹层测试覆盖底部贴边、边界滑动、页签位置恢复和后台进度刷新；两类 APK 的版本和证书均已核对。本次未连接实机，也未调用付费模型验证生成效果。
