# MoRead · 墨知 1.1.1

## 中文

### 页面切换稳定性

- 统一根页与二级页的进退场动画；根页互切取消整页缩放，减少背景渐变漂移。
- 根页安全区不再随阅读页系统栏显隐改变，修复退出沉浸阅读时内容突然下移的问题。
- 宽屏侧栏留白改由各根页独立承担，避免导航期间共享页面视口宽度突变。
- 底部导航采用淡入淡出，退场期间保留原选中项，避免选中胶囊收缩闪动。

### 阅读统计与本地存储

- 阅读统计支持总 / 年 / 月 / 周 / 日切换，新增大格热力、封面月历、阅读时间线、时段分析及标签 / 作者云；组件可调整显示与顺序。
- 按书展示连续阅读日期，点选月历查看当天阅读记录；改进跨午夜、跨周及跨年的时长和日期统计。
- 新增分块正文压缩，保持章节、批注和阅读位置的坐标不变；兼容既有明文正文。
- EPUB 布局与图片支持按需读取和归档缓存，减少重复副本；存储管理增加分类占用图表与压缩反馈。

### AI 设置与主动段评

- 优化供应商、模型分配与搜索设置界面，加入本地供应商 / 模型图标。
- 温度、最大生成长度和 Top P 可单独编辑，保留供应商继承关系及其他高级 JSON 参数。
- 主动段评支持角色选择与独立提示词预设，可分别启停、编辑并选择注入位置；原文定位与防剧透约束保持生效。

### 升级与验证

- 版本 **1.1.1**，versionCode **75**，Room 数据库升级至 **30**；通过迁移保留现有数据。
- 使用本页正式签名 APK 覆盖相同签名的旧正式版。performance 使用开发证书，仅用于开发机，不作为 Release 附件。
- 本地执行完整单元测试、release 与 performance 构建，并核对两种 APK 的版本及签名。
- **1369 项测试：1363 通过、6 项条件跳过、0 失败**。新增 8 项导航回归，覆盖生产 NavHost / Scaffold 内的逐帧几何、系统栏切换、宽屏布局、导航选中态及列表锚点恢复。
- 本次未连接真机，也未调用付费模型服务；自动化测试不替代具体机型与供应商的使用验证。

## English

### More stable navigation

- Root/child navigation now uses paired horizontal transitions. Root-tab switches no longer scale the entire page or its background gradient.
- Root-page safe areas stay stable when the reader hides or restores system bars, avoiding a vertical jump when leaving immersive reading.
- Each root page reserves its own wide-screen navigation-rail space, without resizing the shared navigation viewport during a transition.
- The navigation dock fades in and out while retaining the selected item throughout its exit.

### Reading statistics and local storage

- All-time, yearly, monthly, weekly, and daily statistics include larger heatmaps, a book-cover calendar, reading timelines, time-of-day analysis, and tag/author clouds. Widgets can be hidden and reordered.
- View consecutive reading dates per book and open a calendar date for its reading record. Date/time aggregation handles midnight, week, and year boundaries.
- Block-based text compression preserves chapter, annotation, and reading-position offsets, with continued support for existing plain-text data.
- On-demand EPUB layout/image access and archive caches reduce duplicate files. Storage management adds category charts and compression feedback.

### AI settings and proactive annotations

- Refined provider, model-assignment, and search settings with local provider/model icons.
- Edit temperature, maximum output length, and Top P individually while preserving provider inheritance and unrelated advanced JSON options.
- Proactive annotations support character selection and separate prompt presets with individual enable switches and injection positions. Source-location and spoiler boundaries remain enforced.

### Upgrade and verification

- Version **1.1.1**, versionCode **75**, Room schema **30**, with migrations for existing data.
- Install the officially signed APK over an official installation with the same certificate. Performance builds use the development certificate and are not release assets.
- Local unit tests, release and performance builds, and APK version/signature verification completed successfully.
- **1,369 tests: 1,363 passed, 6 conditional skips, 0 failures.** Eight new navigation checks cover frame-by-frame geometry, system-bar changes, wide screens, dock selection, and restored list anchors in the production NavHost/Scaffold.
- No physical device or paid model service was used for this verification. Automated checks do not replace device- and provider-specific testing.
