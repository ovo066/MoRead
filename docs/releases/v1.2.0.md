# MoRead · 墨知 1.2.0

## 中文

### 插图、人物与画风

- 新增插图工作室，为每本书保存统一画风，支持内置画风、参考图片与人物定妆。
- 新增独立 DIY 画风编辑页，可从空白开始或复制现有画风，设置名称、描述、参考图及高级参数，保存为跨书复用的模板。
- 人物支持上传参考图、生成三视图候选，并按章节保存形象版本；生图时结合已读原文和所选人物的外貌资料。
- 保存生成配方，支持同配方重来、调整后生成，以及将结果用于人物定妆、画风参考、封面或伴读头像。
- 新增章节批量插图队列：预览场景与人物后开始，支持暂停、继续和单项失败重试；应用重启后不会自动重发状态未知的付费请求。
- 接入 OpenAI 图生图与受支持的 NovelAI 参考/Vibe 能力，参考资料随完整备份保存。各模型的参考图能力与一致性效果有所不同。

### 听书与音色

- 新增 Gemini TTS，支持预设及在线音色浏览，系统 TTS 可选择引擎提供的音色。
- 新增音色设计，可通过 AI 对话或手动描述创建候选，试听后保存到音色库。
- 改进有声书对白归属、人物音色分配与保存，减少重新处理章节时的配音变化。

### 阅读与界面

- 支持 EPUB 从右向左竖排、Unicode 竖排字向、竖排标点与纵中横，并适配选词、批注和翻页。
- 扩展受支持的 CSS 渐变、边框、文字阴影与定位，改进特殊字体和高亮文本的测量。
- 优化阅读主题的文字对比度，以及划线与笔记的筛选、字体、全屏翻阅与分享体验。
- 统一底部弹层的滚动边界与主题，改善导航列表越界、页签切换和进度刷新时的稳定性。
- 新增应用内语言选择。英文翻译仍在逐步补齐，未翻译的页面会继续显示中文。

正式安装包：`mozhi-1.2.0-vc78.apk`，Android 8.0 及以上。使用正式发布证书，可覆盖安装已有正式版。

## English

### Illustrations, characters, and styles

- Add a book illustration studio with saved book styles, built-in presets, reference images, and character appearance profiles.
- Create reusable style templates in a dedicated DIY editor, starting from a blank style or a copy, with descriptions, reference images, and optional advanced settings.
- Upload character references or generate turnaround candidates, with appearance versions scoped to chapters and source evidence limited to reading progress.
- Save generation recipes, regenerate or adjust results, and reuse images as character references, style references, covers, or companion avatars.
- Preview and run chapter illustration queues with pause, resume, and individual retries. Requests with uncertain completion are not automatically replayed after restart.
- Support OpenAI image editing and model-specific NovelAI reference/Vibe features. Full backups include reference assets; available controls and consistency vary by model.

### Speech and voice design

- Add Gemini TTS, preset and online voice browsing, and voice selection for system TTS engines.
- Design voices through an AI conversation or manual descriptions, preview candidates, and save selected voices to the voice library.
- Improve dialogue attribution and persistent character voice assignments for audiobooks.

### Reading and interface

- Support right-to-left vertical EPUB writing, Unicode vertical orientation, vertical punctuation, and upright text combinations, including selection, annotations, and page turns.
- Extend supported CSS gradients, borders, text shadows, and positioning; improve font and highlighted-text measurement.
- Refine automatic text contrast, highlights-and-notes filtering, fonts, full-screen browsing, and sharing.
- Unify bottom-sheet themes and scroll boundaries; improve navigation stability during overscroll, tab changes, and progress updates.
- Add in-app language selection. English coverage remains partial, with untranslated pages falling back to Chinese.

Official package: `mozhi-1.2.0-vc78.apk`, for Android 8.0 or later. Signed with the official release certificate and compatible with existing official installations.
