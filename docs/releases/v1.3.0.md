# MoRead · 墨知 1.3.0

## 中文

### 听书与伴读

- 新增小米 MiMo 与 Fish Studio（Fish Audio）语音服务，支持对应服务的音色与朗读参数。
- 陪伴足迹新增共读时间线、交流时段分布、首次交流与交流次数里程碑，并展示相关长期记忆。
- 主动段评额度改为直接输入数字，支持「不限」；每章有限额度最高 99 条，每日有限额度最高 999 条。
- 改进人物与章节大纲整理结果的兼容和校验，支持纠正未通过核对的文本 JSON 输出。

### 阅读与界面

- 生词本改为单词卡片，支持搜索筛选、掌握状态管理与可撤销操作。
- 改进词典弹层的网页滚动边界，减少快速滑动和越界滚动对父弹层的影响。
- 书籍详情新增封面取色与背景氛围，调整信息层级和划线入口。
- 优化划线与笔记详情、全屏回顾的翻卡动效与原文定位，改进阅读页批注标记的稳定性。
- 调整共用数字输入、阅读工具窗口和手机／平板页面适配，同步中英文说明与公开代码地图。

正式安装包：`mozhi-1.3.0-vc79.apk`，Android 8.0 及以上。使用正式发布证书，可覆盖安装已有正式版。

## English

### Speech and companions

- Add Xiaomi MiMo and Fish Studio (Fish Audio) speech providers with provider-specific voice and narration controls.
- Add a shared-reading timeline, conversation-hour distribution, first-conversation and conversation-count milestones, and related long-term memories to companion statistics.
- Replace proactive annotation quota sliders with numeric inputs and an unlimited option; finite quotas support up to 99 annotations per chapter and 999 per day.
- Improve parsing and validation of character and chapter-outline results, including correction rounds for text-only JSON responses.

### Reading and interface

- Redesign the vocabulary book with word cards, search and filters, mastery controls, and undoable actions.
- Improve dictionary web scrolling at sheet boundaries during fast swipes and overscroll.
- Add cover-derived colors and atmospheric backgrounds to book details, with clearer information and highlight entry points.
- Refine highlight-and-note details, full-screen review card motion, source navigation, and annotation mark stability.
- Update shared numeric controls, reading-tool windows, phone and tablet layouts, bilingual documentation, and the public code map.

Official package: `mozhi-1.3.0-vc79.apk`, for Android 8.0 or later. Signed with the official release certificate and compatible with existing official installations.
