# MoRead · 墨知 1.3.1

## 中文

### AI 与伴读

- 独立只读工具调用支持并行执行；伴读过程显示可选择隐藏、简洁或详细，并分别控制思考、参数与结果预览。
- 书籍原文与网页来源改用脚注式引用，可展开引文上下文并返回原文或打开网页。
- 伴读可生成柱状图、折线图、饼图、雷达图、关系图与时间线，支持放大和导出。
- 人物页新增快速调研，通过主任务与并行子任务整理人物资料。
- 改进主动段评的当前章节优先级、失败重试与请求取消，减少切章后任务等待和过期请求。

### 阅读与管理

- 阅读辅助扩展到多种语言，可设置本书学习语言与译文目标语言。
- 书籍、字体、图片与角色卡导入支持重复检测；划线与笔记支持多选管理和批量操作。
- 精简阅读菜单、选文工具栏与 AI 设置，将低频选项收进二级页面。
- 改进词典文件与文件夹导入，自动关联配套 MDD、CSS、字体和图片；支持旧式 MDX 编号样式，保留词典原有排版层级，并改善夜间颜色和滚动位置保持。
- 改进 EPUB 出版样式兼容，支持关联样式表和更多文字装饰线型、颜色，保留链接的原书样式。
- 修复滚动阅读的已读范围记录，只根据实际显示的正文更新阅读进度与伴读上下文。
- 新增 ElevenLabs 听书服务，支持音色 ID、模型和语音调节参数。

正式安装包：`mozhi-1.3.1-vc81.apk`，Android 8.0 及以上。使用正式发布证书，可覆盖安装已有正式版。数据库升级至版本 33，通过迁移保留现有数据。

## English

### AI and companions

- Run independent read-only tool calls in parallel. Choose hidden, concise, or detailed process displays with separate controls for reasoning, arguments, and result previews.
- Present book quotes and web sources as footnotes with expandable context and source navigation.
- Create bar, line, pie, radar, relationship, and timeline charts in companion conversations, with enlargement and image export.
- Add quick character research with a lead task and parallel research tasks.
- Improve proactive annotation scheduling, current-chapter priority, failure retries, and request cancellation.

### Reading and management

- Extend reading aids to multiple languages with per-book learning languages and configurable translation targets.
- Detect duplicate books, fonts, images, and persona cards during import. Add multi-select management and batch actions for highlights and notes.
- Simplify reader menus, selection toolbars, and AI settings with secondary pages for less frequent options.
- Improve dictionary imports by associating MDD, CSS, fonts, and images. Support legacy MDX numbered styles, preserve dictionary typography, and improve night colors and scroll position retention.
- Improve EPUB publisher-style compatibility with imported stylesheets, additional text-decoration styles and colors, and original link styling.
- Fix read-range tracking in scrolling mode so reading progress and companion context follow the text actually displayed.
- Add ElevenLabs narration with voice IDs, model selection, and speech tuning controls.

Official package: `mozhi-1.3.1-vc81.apk`, for Android 8.0 or later. Signed with the official release certificate and compatible with existing official installations. Database version 33 includes migrations preserving existing data.
