# MoRead · 墨知 1.6.0

## 中文

**导入**
- 新增 Markdown、HTML 与无 DRM 的 MOBI / AZW3 导入：转成 EPUB 后沿用原有阅读、排版与批注能力，转换全程不联网；带 DRM 或暂不支持的文件会给出明确原因。

**伴读**
- 随读配图改为按段落画面感挑选，每章上限可设；生图服务未配置时不再空耗额度，设置页显示今日语音、插图用量与失败次数。
- 多位伴读参与段评时互相看得见：不重复划同一段，偶尔在讨论里接一句；讨论串新增「大家聊聊」，几位伴读轮流各说一句。
- 阅读菜单「更多」新增「插图排进正文」（按书开关，默认关）：已生成的插图像出版书那样排在段落之间，图注标明 AI 配图，不改变原文与阅读进度。

**演出模式**
- 说话人有定妆图时，名牌旁显示小像；已生成的插图演到那一句时出现。
- 配音跟读：章节做过有声书时，演到哪句放哪句，自动播放等配音念完再走。
- 旁白节奏（逐句 / 合句 / 整段）、全屏演出、旁白冷暖色，并修复精排书对白颜色丢失。

**阅读**
- 操作区新增一键预设（标准 / 全屏翻页 / 左手 / 上下）；页眉页脚改为左中右六个槽位；左右边距可调到 0。

正式安装包：`mozhi-1.6.0-vc90.apk`，Android 8.0 及以上，使用正式发布证书，可覆盖安装已有正式版。

## English

**Import**
- Import Markdown, HTML and DRM-free MOBI / AZW3. Files are converted to EPUB locally and then use the existing reading, layout and annotation features. Nothing is fetched from the network; DRM-protected or unsupported files are rejected with a clear reason.

**Companions**
- Proactive illustrations are now chosen by how visual a passage is, with a per-chapter limit. No quota is spent when no image service is configured, and settings show today's voice and image use and failures.
- When several companions comment, they see each other: they do not mark the same passage twice and sometimes add a line in the thread. A new “Let them talk” button lets companions take turns.
- New per-book “Illustrations in the text” (More menu, off by default): generated pictures sit between paragraphs like a printed book, captioned as AI illustrations, without changing the source text or reading progress.

**Stage mode**
- Speakers with a reference look get a small portrait beside the name tag; generated illustrations appear at their line.
- Audiobook voices: if a chapter has an audiobook, each line plays its recorded voice and auto-play waits for it to finish.
- Narration rhythm (per sentence / merged / per paragraph), full-screen stage, warm and cold tints for narration, and a fix for lost dialogue colours in rich EPUBs.

**Reading**
- One-tap tap-zone presets (standard / full-screen turns / left-handed / up-down), six header and footer slots, and side margins down to zero.

Official package: `mozhi-1.6.0-vc90.apk`, for Android 8.0 or later. Signed with the official release certificate for upgrades from existing official installations.
